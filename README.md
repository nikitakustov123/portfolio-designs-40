# 40 портфолио

Автор: **nikitakustov123**

Сорок самостоятельных дизайнов сайтов-портфолио. У каждого своя тема, профессия, палитра, шрифты и свой фирменный эффект: canvas, SVG, Web Audio или 3D на CSS.

Галерея онлайн: https://nikitakustov123.github.io/portfolio-designs-40/

Откройте `index.html` — это галерея с живыми превью всех работ. Каждый дизайн — это один файл `designs/<номер-название>/index.html` без зависимостей и сборки (шрифты подключаются из Google Fonts).

## Как посмотреть

- **GitHub Pages:** Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`. Через минуту галерея откроется по адресу `https://<логин>.github.io/<репозиторий>/`.
- **Локально:** `python3 -m http.server` в корне репозитория и откройте `http://localhost:8000`.

## Что внутри каждого

- адаптивная вёрстка до мобильных экранов;
- видимый фокус для клавиатуры;
- `prefers-reduced-motion` — анимации отключаются, если человек так настроил систему;
- никаких фреймворков и картинок: вся графика нарисована CSS, SVG и canvas.

Проекты и цифры на страницах — демонстрационное наполнение. Почта в контактах — `hello@example.com`, замените на свою.
