# 40 portfolios

Designed by **nikitakustov123**

Forty standalone portfolio website designs. Each has its own profession, palette, typefaces and signature effect: canvas, SVG, Web Audio or CSS 3D.

> **These are concept designs.** Names of projects, clients, awards and all figures on the pages are placeholder content — not real work.

Live gallery: https://nikitakustov123.github.io/portfolio-designs-40/

## Viewing

- **GitHub Pages:** the gallery is published from the `main` branch at the link above.
- **Locally:** run `python3 -m http.server` in the repository root and open `http://localhost:8000`.

Each design is a single file, `designs/<number-name>/index.html`, with no dependencies or build step (fonts load from Google Fonts).

## In every design

- responsive layout down to phone screens;
- visible keyboard focus;
- `prefers-reduced-motion` support — animations switch off if the visitor asks for less motion;
- no frameworks and no images: all graphics are drawn with CSS, SVG and canvas.

Contact addresses use `hello@example.com` as a placeholder.
